📲 Install as an app

Add the tools to your home screen: they open full-screen like an app, start faster, and the pages you've used work even without internet.

On iPhone / iPad: open this page in Safari → tap the Share button (square with an arrow) → Add to Home Screen → Add.
No install button? In Chrome, open the ⋮ menu → Install app or Add to Home screen. On a computer, look for the install icon at the right end of the address bar.
🔐 Privacy: your data never leaves your device unless you send the backup file somewhere yourself. There's no account and no server: the backup file is the only copy outside this browser, so keep it somewhere safe. It may contain names from your community (leaderboards) and your trade journal.
